# 🤖 AI Driven Smart Ticketing System


## Project Overview

AI based customer support ticket management system
that automatically classifies customer problems,
predicts priority, analyzes sentiment and generates
AI responses.



## Features


### Customer Module

- Register/Login
- Create Ticket
- View Ticket Status
- AI Chat Support



### AI Features

- Ticket Category Prediction
- Priority Prediction
- Sentiment Analysis
- Similar Ticket Detection
- AI Reply Generation
- Gemini AI Chatbot



### Agent Module

- Agent Dashboard
- Search Tickets
- Filter Tickets
- Update Status
- AI Recommendation



### Analytics

- Ticket Statistics
- Category Analysis
- Priority Charts
- Sentiment Charts
